# .NET

> The **.NET platform** (pronounced as "_dot net_"; formerly named .NET Core) is a free and open-source, managed computer software framework for Windows, Linux, and macOS operating systems. It is a cross-platform successor to the .NET Framework. The project is mainly developed by Microsoft employees by way of the .NET Foundation and is today released under an MIT License.
>
> New versions of the .NET platform are released annually, typically in November.
>
