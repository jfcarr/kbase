## Editing Notes (mdbook)

### Admonitions

Example:

```txt
> [!IMPORTANT]
> It is absolutely critical that you use the correct device name in this step. Using the wrong name can result in you wiping out the wrong drive!
```

All admonition tags:

```txt
> [!NOTE]
> General information or additional context.

> [!TIP]
> A helpful suggestion or best practice.

> [!IMPORTANT]
> Key information that shouldn't be missed.

> [!WARNING]
> Critical information that highlights a potential risk.

> [!CAUTION]
> Information about potential issues that require caution.
```
